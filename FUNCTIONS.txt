=====================================================================
  Z2A Store - شرح الفانكشنز الأساسية اللي اتعملت
=====================================================================

الملف ده بيشرح كل حاجة أساسية في المشروع بالعربي، وكل فانكشن موجودة فين
وبتعمل إيه.

---------------------------------------------------------------------
0) أهم تنبيه قبل ما تبدأ
---------------------------------------------------------------------
- المشروع كله شغال في المتصفح بس (Front-end). كل البيانات (منتجات، أقسام،
  مستخدمين، أوردرات، سلة) بتتخزن في localStorage على الجهاز اللي بيفتح الموقع.
  يعني ده "قاعدة بيانات تجريبية": لو فتحت الموقع من جهاز تاني مش هتشوف نفس
  الداتا، ولو مسحت بيانات المتصفح كل حاجة بتتمسح.
- الأدوار (owner / admin / user) شغالة فعلًا جوه الموقع، لكن الأمان الحقيقي
  (إن حد ميقدرش يعدل الداتا بالإيد من الـ DevTools) محتاج Backend وقاعدة
  بيانات حقيقية. شوف الجزء (9) في آخر الملف.
- أول حساب بتعمله (Create account) بيبقى Owner تلقائي. مفيش يوزر وباسورد
  جاهزين، عشان مفيش باسورد افتراضي حد يعرفه.

2) التخزين: src/storage.js و usePersistentState.js
---------------------------------------------------------------------
load(key, fallback)
   بتقرا قيمة من localStorage (بادئة المفاتيح z2a:). لو مفيش أو حصل خطأ
   بترجّع fallback.

save(key, value)
   بتحفظ القيمة كـ JSON. لو التخزين مليان بترجّع false بدل ما الموقع يقع.

uid(prefix)
   بتعمل ID فريد للمنتج/القسم/اليوزر/الأوردر.

hashPassword(password, salt)
   بتعمل SHA-256 للباسورد مع "salt" مختلف لكل يوزر، فالباسورد نفسه عمره ما
   بيتخزن. (لو المتصفح مفيهوش Web Crypto - زي http عادي - بتستخدم دالة
   بديلة أضعف.)

fileToDataUrl(file, max = 800)
   بتاخد صورة المنتج اللي الأدمن رفعها، تصغّرها لحد 800px وتحوّلها JPEG
   صغيرة (Data URL) عشان تتخزن في localStorage من غير ما تملاه.

usePersistentState(key, initial)
   زي useState بالظبط بس أي تغيير بيتحفظ لوحده، وبيرجع بعد الريفريش.

3) StoreProvider.jsx (البيانات والصلاحيات)
---------------------------------------------------------------------
الحالة: categories, products, users, orders, sessionId, cart.
المتغيرات الجاهزة: user (المستخدم الحالي بدون الهاش)، isOwner، isStaff
(owner أو admin)، cartLines، cartCount، cartTotal.

السلة
- addToCart(id, qty)      بتضيف للسلة بشرط إن المنتج متاح والكمية مش أكبر
                          من المخزون. بترجّع {ok} أو {ok:false, error}.
- setCartQty(id, qty)     بتغيّر الكمية (مع حد أقصى = المخزون، و0 = حذف).
- removeFromCart(id)      بتحذف من السلة.

الحسابات
- register({name,email,password})
     بتعمل حساب جديد. بترفض الباسورد أقل من 6 أحرف والإيميل المكرر.
     أول حساب في الموقع = owner، وبعد كده كل الحسابات = user.
- login({email,password})  بتتأكد من الباسورد بالهاش وتفتح الجلسة.
- logout()                 بتقفل الجلسة.

الطلبات (Orders)
- createOrder(customer)
     بتتأكد إن المستخدم داخل والسلة مش فاضية والمخزون كفاية، وبعدين:
       * بتعمل رقم أوردر (Z2A-1001, 1002 ...) وتاريخ ووقت
       * بتخزن نسخة من المنتجات والأسعار وقت الشراء (عشان التعديل بعد كده
         في السعر ميغيّرش أوردر قديم)
       * بتنقّص المخزون وتفضّي السلة
- updateOrderStatus(id, status)
     (أدمن/أونر فقط) بتغيّر الحالة: pending / confirmed / shipped /
     delivered / cancelled. لو اتلغى الأوردر المخزون بيرجع، والأوردر
     الملغي بيتقفل ومينفعش يتغير تاني.

المنتجات والأقسام (أدمن/أونر فقط)
- saveProduct(draft)      إضافة أو تعديل منتج. بتتحقق من: الاسم الإنجليزي،
                          القسم، السعر والمخزون أرقام صحيحة، والسعر قبل
                          الخصم لازم يكون أكبر من السعر بعد الخصم.
- deleteProduct(id)       حذف منتج (وبيتشال من السلة).
- saveCategory(draft)     إضافة/تعديل قسم (بترجّع الـ id بتاعه).
- deleteCategory(id)      حذف قسم، بس لو مفيهوش منتجات.

المستخدمين (أونر فقط)
- setUserRole(id, role)   تغيير الدور (owner / admin / user). مينفعش تغيّر
                          دور نفسك.
- deleteUser(id)          حذف مستخدم. مينفعش تحذف نفسك.
- resetDemo()             رجوع المنتجات والأقسام للبيانات التجريبية.

كل دالة من اللي فوق بتتحقق من الصلاحية جواها، مش بس بإخفاء الأزرار.
الهاش والـ salt مبيتبعتوش للواجهة خالص (users بتتصفّى قبل ما تتعرض).

7) لوحة الأدمن (admin.jsx)
---------------------------------------------------------------------
الصفحة بتفتح بس لو دورك owner أو admin، غير كده بتظهر رسالة "غير مسموح".

Overview     أرقام سريعة: عدد المنتجات، المخزون المنخفض/النافد، الأوردرات،
             اللي قيد المراجعة، الإيراد (من غير الملغي)، المستخدمين، وآخر
             5 أوردرات.
Products     إضافة/تعديل/حذف منتج بالحقول:
               - الاسم والتفاصيل (عربي + إنجليزي)
               - القسم (ومعاه زرار "+ قسم جديد" من نفس الفورم)
               - السعر بعد الخصم والسعر قبل الخصم
               - الكمية في المخزون
               - متاح للبيع / غير متوفر
               - رفع صورة المنتج
             والجدول بيبيّن المخزون الأحمر لو 5 أو أقل.
Categories   إضافة/تعديل/حذف أقسام (اسم عربي + إنجليزي + أيقونة).
Orders       كل الأوردرات مع رقم الأوردر والتاريخ والعميل والإجمالي والحالة،
             بحث برقم الأوردر أو اسم العميل أو التليفون، فلتر بالحالة،
             وزرار Details بيفتح المنتجات والعنوان والتليفون والملاحظات.
Users        قايمة المستخدمين والأدوار. الأونر بس يقدر يغيّر الدور أو يحذف.

صلاحيات الأدوار:
  owner  = كل حاجة + إدارة المستخدمين والأدوار + إعادة البيانات التجريبية
  admin  = المنتجات + الأقسام + الأوردرات (يشوف المستخدمين بس)
  user   = يتسوق ويشوف طلباته بس

8) اللوجو والخط

  (-apple-system / SF Pro / SF Arabic). ده بيظهر فعلًا على أجهزة Apple.
  على باقي الأجهزة بيستخدم خط النظام (Segoe UI / Roboto / Noto Sans Arabic)
  لأن Apple مبتسمحش بتوزيع الخط على الويب.

---------------------------------------------------------------------
9) الخطوة الجاية عشان الموقع يبقى حقيقي 100%
---------------------------------------------------------------------
1. Backend + قاعدة بيانات (مثلًا Supabase أو Firebase أو Node + PostgreSQL)
   بدل localStorage. كل دالة في StoreProvider تقابل طلب API:
   register/login -> حسابات مع JWT أو جلسة، createOrder -> POST /orders،
   saveProduct -> POST/PUT /products، ... إلخ.
2. التحقق من الصلاحيات (owner/admin/user) لازم يتعمل على السيرفر.
3. رفع الصور على Storage (S3 / Cloudinary) بدل Data URL.
4. دفع أونلاين (حاليًا الدفع عند الاستلام بس).
5. عند النشر لازم تضبط السيرفر يرجّع index.html لأي مسار (SPA fallback)
   عشان /shop و /admin يشتغلوا بعد الريفريش (Netlify: ملف _redirects،
   Vercel: rewrites، Nginx: try_files).
6. إيميل التواصل والتليفون وروابط السوشيال: src/data.js و Layers/Foot.jsx.

10) إزاي تجرّب
---------------------------------------------------------------------
  npm install
  npm run dev
1) اعمل Create account -> هتبقى Owner.
2) من القائمة بتاعتك (فوق) افتح Dashboard وضيف منتجات وأقسام.
3) اشتري منتج وشوف الأوردر في Dashboard > Orders.
4) سجّل بحساب تاني -> هيبقى user، والأونر يقدر يخليه admin من Users.
