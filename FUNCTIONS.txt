=====================================================================
  Z2A Store - شرح الفانكشنز الأساسية (النسخة اللي فيها Node.js + MongoDB)
=====================================================================

الفكرة العامة
-------------
الموقع دلوقتي 3 طبقات:
  1) المتصفح (React) .......... Layers/ و src/
  2) السيرفر (Node + Express) .. server/   بيتكلم مع قاعدة البيانات ويحمي الصلاحيات
  3) قاعدة البيانات (MongoDB) ... المنتجات، الأقسام، المستخدمين، الأوردرات، الصور

أهم فرق عن النسخة القديمة: مفيش localStorage للداتا خلاص. الداتا في MongoDB وأي
جهاز يفتح الموقع يشوف نفس المنتجات. الوحيد اللي لسه في المتصفح هو: السلة،
اللغة، والثيم.

تشغيل سريع: npm install  ->  cp .env.example .env  ->  npm run dev
(شرح كامل للـ MongoDB والـ Docker والنشر في README.md)

---------------------------------------------------------------------
1) السيرفر (server/)
---------------------------------------------------------------------
config.js        بيقرا ملف .env. في الإنتاج بيرفض يشتغل من غير JWT_SECRET قوي.
db.js            الاتصال بـ MongoDB، ولو فشل بيطبع رسالة مفهومة تقولك تشغّل Mongo.
models/index.js  شكل الداتا: User, Category, Product, Order, Image, Counter.
seed.js          بيملا قاعدة فاضية بأقسام ومنتجات تجريبية (npm run seed).

routes/auth.js
  POST /api/auth/register   إنشاء حساب. الباسورد بيتشفّر بـ bcrypt. أول حساب (أو
                            الإيميل اللي في OWNER_EMAIL) = owner، والباقي = user.
  POST /api/auth/login      بيتحقق ويحط كوكي httpOnly فيه JWT (لا يقرأه JavaScript).
  POST /api/auth/logout     بيمسح الكوكي.
  GET  /api/auth/me         المستخدم الحالي.

routes/catalog.js
  GET  /api/categories , /api/products     للكل.
  POST/PUT/DELETE                          للمشرف (admin) والمالك (owner) بس.
  - بيتحقق إن السعر قبل الخصم >= السعر بعده، والمخزون رقم صحيح، والقسم موجود.
  - لو غيّرت صورة منتج/قسم الصورة القديمة بتتمسح من قاعدة البيانات.
  - مينفعش تمسح قسم فيه منتجات.

routes/orders.js
  POST /api/orders          عمل أوردر. السيرفر بياخد الأسعار والمخزون من قاعدة
                            البيانات (مش من المتصفح)، وبينقّص المخزون بعملية
                            "ذرّية" (findOneAndUpdate مع $gte) فلو اتنين اشتروا آخر
                            قطعة مع بعض واحد بس ينجح. رقم الأوردر Z2A-1001... من
                            عدّاد في قاعدة البيانات. لو حصل خطأ بيرجّع المخزون.
  GET  /api/orders/mine     أوردرات المستخدم.
  GET  /api/orders          كل الأوردرات (مشرف/مالك).
  PATCH /api/orders/:id/status   تغيير الحالة. الإلغاء بيرجّع المخزون مرة واحدة بس
                            والأوردر الملغي بيتقفل.

routes/users.js    قايمة المستخدمين (مشرف/مالك). تغيير الدور وحذف مستخدم = المالك فقط،
                   ومينفعش المالك يغيّر دور نفسه أو يحذف نفسه.
routes/uploads.js  POST /api/uploads (مشرف/مالك) رفع صورة. بيفحص الملف الحقيقي
                   (JPG/PNG/WebP بس، الـ SVG ممنوع) ويحفظه في MongoDB.
                   GET /api/images/:id بيعرض الصورة للكل مع كاش طويل.
routes/admin.js    إعادة البيانات التجريبية (مالك فقط).

middleware/auth.js      loadUser بيحمّل المستخدم من قاعدة البيانات في كل طلب (فتغيير
                        الدور بيسري فورًا). requireAuth / requireStaff / requireOwner.
middleware/security.js  sameOrigin يرفض طلبات التعديل من مواقع تانية (CSRF)، و
                        errorHandler يرجّع أخطاء بمفاتيح الترجمة (err.stock مثلًا)
                        والموقع بيترجمها عربي/إنجليزي.
app.js                  Helmet (CSP وغيره)، ضغط، حد محاولات الدخول، وتقديم الموقع
                        المبني (dist) في الإنتاج مع إرجاع index.html لأي صفحة.

---------------------------------------------------------------------
2) الموقع (src/ و Layers/)
---------------------------------------------------------------------
src/api.js          دالة fetch واحدة لكل الاتصالات. لو السيرفر مش شغال بترمي
                    err.network.
src/StoreProvider.jsx   بيحمّل الأقسام والمنتجات والجلسة عند الفتح، وفيه كل العمليات
                    (login, register, createOrder, saveProduct, uploadImage ...).
                    كلها بترجّع {ok:true} أو {ok:false, error:'مفتاح الترجمة'}.
                    فيه ready (خلّص التحميل) و offline (السيرفر مش متاح) وبانر
                    "حاول مرة أخرى".
src/storage.js      resizeImage: بتصغّر الصورة (حد أقصى 1200px) وتحوّلها JPEG قبل
                    الرفع.

الصور بدل الأيقونات
  Layers/Photo.jsx          المكوّن الوحيد اللي بيعرض أي صورة. لو مفيش صورة بيعرض
                            لوجو Z2A على خلفية كحلية.
  Layers/CategoryCard.jsx   كارت القسم بصورته (السلايدر + صفحة الأقسام).
  Layers/admin/ImageField.jsx  اختيار الصورة ورفعها (للمنتج وللقسم).

السلايدر المتحرك (Layers/Categories.jsx)
  بيتحرك لوحده بسرعة ثابتة في لفّة متصلة (القايمة بتتكرر)، ويقف لما تحط الماوس أو
  تلمس أو تستخدم الكيبورد، وفيه أسهم وسحب بالإيد. بيشتغل في العربي (RTL) كمان
  وبيحترم "reduce motion".

الـ 3D
  Layers/Logo3D.jsx   اللوجو كـ 18-22 طبقة متراصّة بعمق (CSS 3D) بألوان من البرونزي
                      للذهبي للعاجي فيبان له سُمك.
  Layers/Hero3D.jsx   بانر الهيرو: لوجو 3D طاير، مدارات بتلف، توهج، نجوم، وبيميل
                      ناحية الماوس.
  Layers/Welcome.jsx  أنيميشن "Welcome to Z2A" بـ 3D مرة واحدة في كل زيارة (حوالي
                      3.3 ثانية)، والضغط في أي مكان بيتخطاه.

صفحات الدخول (Layers/Auth.jsx)
  /login و /register صفحتين منفصلتين. بعد النجاح بيرجّعك للصفحة اللي كنت عايزها
  (?next=/checkout مثلًا، ومسموح بمسارات الموقع بس).

لوحة التحكم (/admin)
  المنتجات: صورة، اسم/تفاصيل عربي وإنجليزي، قسم (+ قسم جديد من نفس الفورم)، السعر
            قبل وبعد الخصم، المخزون، متاح/غير متاح.
  الأقسام: اسم + صورة.
  الأوردرات: رقم + تاريخ + تفاصيل + تغيير الحالة.   المستخدمون: الأدوار.

---------------------------------------------------------------------
4) قبل ما تنشر
---------------------------------------------------------------------
- JWT_SECRET طويل وعشوائي، و OWNER_EMAIL = إيميلك.
- https + COOKIE_SECURE=true + TRUST_PROXY=true لو ورا proxy.
- Backup دوري لـ MongoDB (الصور كمان جواه).
- الدفع حاليًا عند الاستلام فقط؛ الدفع الأونلاين لسه مش متعمل.
